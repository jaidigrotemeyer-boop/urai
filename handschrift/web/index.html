Zum Umschreiben braucht es ein Sprachmodell. Läuft Ollama daheim, wird es von selbst genommen — ohne Schlüssel, ohne Netz. Sonst genügt ein Gratis-Schlüssel; er bleibt auf diesem Rechner. Messen und Tippen laufen auch ohne beides.
